# Проверка очищенной копии

Дата: 2026-11-07. Цель: KotBot-public, MIT.

Копирование выполнено по списку исходников без .git, .env, баз, журналов, резервных копий, виртуальных окружений и внутренних инструкций. Серверные unit-файлы и частный скрипт миграции исключены. Модель вынесена в OPENAI_MODEL, путь базы по умолчанию обезличен. Иконка и вымышленная персона Kater сохранены как часть проекта.

Проверено: синтаксис всех Python-файлов через ast.parse; всех JavaScript-файлов через node --check; JSON манифеста; поиск известных приватных реквизитов, шаблонов OpenAI/Telegram токенов и приватных ключей — совпадений нет. Это ограниченный статический аудит, не доказательство отсутствия всех возможных уязвимостей.

Полный запуск API, вход Mini App, отправка в Telegram и вызовы OpenAI из этой копии не выполнялись. Для них нужны собственные секреты и отдельное тестовое окружение. Production не менялся. Публикация на GitHub не выполнялась.
