# KotBot-public

Kater — Telegram-бот с характером ворчливого немецкого кота и отдельным Web/PWA-клиентом. Разработан владельцем при участии ИИ-агентов. Эта копия подготовлена отдельно от приватного рабочего репозитория, без его истории, секретов и данных переписки.

## Возможности

- Текст и изображения через OpenAI Chat Completions.
- Персона в `persona.py`, различение владельца и гостей по Telegram ID.
- SQLite: общая история Telegram и веба, последние 20 реплик на чат.
- Web/PWA: светлая и тёмная темы, вставка изображения из буфера.
- Telegram Mini App: проверка initData, вход только владельцу, ярлык на экран.
- Сообщения из веба зеркалируются ботом в личный Telegram-чат владельца.

## Запуск

Требуется Python 3.12+. Создай виртуальное окружение и установи зависимости:

```sh
python -m venv .venv
python -m pip install -r requirements.txt -r backend/requirements.txt
```

Используй Python и pip из созданного окружения. Скопируй `.env.example` в `.env`, задай собственные значения. Выбери модель с поддержкой изображений и параметров `reasoning_effort` и `max_completion_tokens`: совместимость конкретной модели нужно проверить. `OPENAI_MODEL` читается из окружения; перед запуском обоих процессов передай все настройки из файла в окружение процесса (сам API .env не читает). Для бота `.env` также загружается через python-dotenv.

```sh
python bot.py
python -m uvicorn --app-dir backend app:app --host 127.0.0.1 --port 8101
```

Для общей истории обоим процессам задай один абсолютный `KATER_DB_PATH` и права записи в каталог базы. Для веба требуется HTTPS-прокси: cookie сессии имеет Secure. В BotFather настрой Menu Button на свой HTTPS URL для Mini App. Пароль веба предоставляет доступ от имени владельца.

## Ограничения и данные

Это небольшой персональный проект, а не готовый многопользовательский сервис. Перед открытым размещением нужна отдельная проверка защиты входа, ограничений запросов, загрузок и конкурентной записи. SQLite WAL и busy_timeout не гарантируют порядок одновременных диалогов. Веб-история загружается при открытии, автоматическое обновление между открытыми окнами не реализовано.

Текст контекста и текущее изображение отправляются OpenAI. Изображения сохраняются в SQLite как base64 для интерфейса, но старые изображения повторно модели не передаются. После лимита истории старые записи удаляются; `/clear` удаляет историю чата. Зеркало Telegram работает по лучшей попытке без гарантированной доставки. Не запускай второй polling-процесс с тем же токеном.

Серверные настройки, миграция существующих данных, реальные переписки, внутренние инструкции и приватная история Git в эту копию не входят. Проверка подготовки описана в `AUDIT.md`. Лицензия MIT.
